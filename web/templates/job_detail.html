읽기 전용 보고서
  • Web UI는 보안 판정, 심각도, 카테고리를 새로 만들거나 수정하지 않습니다.
  • HTTP 200, text/html, response_body_bytes, 반복 요청은 그 자체로 공격 성공 증거가 아닙니다.
  • 보고서와 viewer payload는 pipeline 산출물을 표시하는 용도로만 사용합니다.
Apache logs-only 원칙 이 분석은 Apache 로그 기반 아티팩트만 사용합니다. Raw request/response body, DB 쿼리 결과, 브라우저 실행 결과, 서버 내부 상태는 포함하지 않습니다.
