# 진행상황

- 기준 시점: 2026-05-03
- 문서 역할: 현재 상태를 빠르게 확인하는 짧은 대시보드

## 현재 상태 요약

- Apache 웹 로그 기반 LLM 침입 로그 분석 파이프라인을 유지 중이다.
- 구조는 `export -> prepare -> stage1 -> stage2` 이다.
- 분석 근거는 Apache 로그 표면에 직접 남는 필드로 제한한다.
- raw POST body, response body 원문, DB 결과, 브라우저 실행 여부는 사용하지 않는다.
- `status_code=200`, `text/html`, `response_body_bytes`만으로 성공, 침해, 유출을 단정하지 않는다.

  - `HEAD/GET` baseline 과승격 없음
  - `PUT/DELETE/TRACE/OPTIONS` 성공 단정 없음
- G세트 R2: Python raw socket runner 기반 protocol / malformed request 관찰 완료
  - `FAKEMETHOD`, `HTTP/1.0`, bad protocol, missing/odd Host, long path 실행
  - `access=6`, `security=6`, `error=0` 관찰
  - `protocol_anomaly_summaries=1`로 context-only 보존
  - protocol bypass, malformed request 우회, 서버 침해 성공 단정 없음
- G세트 R3: Python runner 기반 baseline / FP bait 검증 완료
  - `HEAD /health`, browser-like `OPTIONS`, normal `GET`, monitoring UA, repeated `HEAD` 실행
  - candidate `0`, `method_behavior_summaries=1`, `protocol_anomaly_summaries=0`
  - 정상 method/baseline 요청은 candidate로 과승격되지 않음
  - CORS 취약점, method 허용, 공격 성공 단정 없음
- H세트 R1: Python runner 기반 static / health / normal browse baseline 검증 완료
  - favicon, robots.txt, sitemap.xml, JS/CSS/image asset, health, normal GET 실행
  - candidate `0`, `static_baseline_summaries=1`
  - static file 존재, robots/sitemap 내용, JS 실행, file exposure, health 정상 여부 단정 없음
- H세트 R2: Python runner 기반 crawler-like baseline 검증 완료
  - Googlebot-like / GenericCrawler-like UA, robots/sitemap, products/category, normal browse 실행
  - candidate `0`, `static_baseline_summaries=1`, `crawler_baseline_summaries=1`
  - 실제 crawler 여부, robots/sitemap 내용, site structure, page existence, 공격 성공 단정 없음

- `py_compile` 주요 스크립트 통과

## 주요 제한

- raw POST body 분석 불가
- response body 원문 없음
- DB query 결과 없음
- 브라우저 실행 검증 없음
- 로그인 성공, 계정 탈취, credential stuffing 성공은 Apache 로그만으로 단정하지 않음
- PUT 업로드 성공, DELETE 삭제 성공, TRACE/XST 성공, OPTIONS/CORS 취약점은 Apache 로그만으로 단정하지 않음
- malformed request 우회, protocol bypass, 서버 침해 성공은 Apache 로그만으로 단정하지 않음
- static file 존재, robots/sitemap 내용, JS 실행, file exposure, health 정상 여부는 Apache 로그만으로 단정하지 않음
- 실제 crawler 여부, site structure, product/category page existence는 Apache 로그만으로 단정하지 않음
- 성공, RCE, 유출, 침해를 status/bytes/content-type만으로 단정하지 않음
- 실험환경 특화 rule 금지
  - `lab-*` UA
  - 특정 IP
  - 특정 response size
  - 특정 제품명
  - 특정 route 예외 처리
