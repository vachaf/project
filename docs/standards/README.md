# standards

## 목적

- `standards/`는 실험 문서 작성 표준과 공통 템플릿을 둔다.
- 세트별 문서에 공통으로 적용되는 절차, 명명 규칙, 기록 형식을 먼저 안내한다.

## 관리 원칙

- 공통 표준과 템플릿만 `standards/`에 둔다.
- 세트별 실험 설계와 실행 문서는 `experiments/`에 둔다.
- 완료 평가나 리뷰 문서는 `reviews/`에 둔다.
