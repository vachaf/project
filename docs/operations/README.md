# operations

## 목적

- `operations/`는 실행 가이드, 운영 기준, 환경 구축, 로그 구조 문서를 둔다.
- `export -> prepare -> stage1 -> stage2` 흐름을 실제로 따라갈 때 필요한 운영 문서를 모아 둔다.
