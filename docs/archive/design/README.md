# design archive

이 디렉터리는 현재 기준 문서에서 내려온 historical design/review 문서를 둔다.

- 현재 기준 문서는 `docs/design/README.md`를 본다.
- archive 문서는 과거 검토 흐름, 당시 분포 관찰, cleanup 판단 근거를 보존한다.
- archive 문서는 기본적으로 현재 운영 기준이나 prepare 정책의 single source of truth가 아니다.

## 현재 보관 문서

- `99_design_docs_cleanup_candidate_review.md`
- `99_prepare_candidate_policy_distribution_review.md`
- `99_prepare_php_sample_candidate_policy_review.md`
- `99_prepare_scanner_probe_context_candidate_demotion_review.md`
- `99_prepare_status_error_only_candidate_demotion_review.md`
- `99_prepare_upload_multipart_sql_comment_false_positive_review.md`
