# planning

## 목적

- `planning/`은 후속 작업 계획, TODO, 우선순위, 장기 후보를 둔다.
- 아직 끝나지 않은 설계 후속 작업과 개선 큐를 짧게 추적할 때 사용한다.

- 구현 설계와 보류 결정은 `design/`에 둔다.
