## 3. 작업 내용 (전체 공동)

### [G세트 HTTP Method / Protocol Anomaly]
* **G R1 method probe 검증**: OPTIONS, TRACE, PUT, DELETE, HEAD, GET 요청을 runner 기반으로 실행하고, method behavior를 `method_behavior_summaries`로 context-only 보존하도록 개선함
* **G R2 protocol anomaly 검증**: raw socket 기반 invalid method, HTTP/1.0, bad protocol, missing Host, odd Host, long path 시나리오를 실행하고 `protocol_anomaly_summaries`로 보존함
* **G R3 baseline 검증**: HEAD/GET/OPTIONS/monitoring UA baseline이 공격으로 과승격되지 않는지 확인함
* **G세트 종합 문서 작성**: G R1/R2/R3 결과를 종합하고 method 허용, protocol bypass, 업로드/삭제/XST/CORS 성공을 단정하지 않는 원칙을 정리함

### [H세트 Static / Crawler / Scanner-like Noise]
* **H세트 설계 및 runner 작성**: `docs/98B_H세트_Static_Crawler_Noise_비교실험.md`를 정리하고 H R1/R2/R3/R4 runner를 추가함
* **H R1 static baseline 검증**: favicon, robots.txt, sitemap.xml, JS/CSS/image asset, health, normal GET 요청이 candidate로 과승격되지 않음을 확인하고 `static_baseline_summaries`를 추가함
* **H R2 crawler-like baseline 검증**: Googlebot-like / GenericCrawler-like 요청을 실제 crawler로 단정하지 않고 `crawler_baseline_summaries`로 보존하도록 개선함
* **H R3 sensitive path 검증**: `.env`, `wp-login.php`, `phpinfo.php`, `server-status`, `backup.zip` 등을 파일 노출/앱 존재/침해 성공으로 단정하지 않고 `sensitive_path_probe_summaries`로 정리함
* **H R4 mixed baseline/scanner 검증**: 정상 browse/static/crawler-like 요청과 scanner-like sensitive path가 섞인 상황을 실행하고 `mixed_baseline_scanner_summaries`로 분리 보존함
* **H세트 종합 문서 작성**: H R1/R2/R3/R4 전체 결과를 `lab/05-03_H세트_산출물/2026-05-03_H세트_종합.md`에 반영함

### [Stage2 / LLM 검증]
* **실제 LLM 샘플 검증 계획 작성**: `docs/99_llm_sample_review_plan.md`를 작성하여 성공 단정 금지, 로그 한계 반영, context-only 준수, severity 적정성, baseline/FP 병기 기준을 정리함
* **FGH 샘플 수동 검증**: F R2B, G R2, H R2, H R3, H R4를 대상으로 실제 Stage1/Stage2 산출물을 검토하고 `lab/LLM샘플검증/2026-05-03_FGH_sample_review.md`에 46/50 결과를 정리함
* **Stage2 wording 품질 검토**: `docs/99_stage2_wording_quality_review.md`를 작성하여 오타, 용어 흔들림, key finding severity 불일치 원인을 분리함
* **key finding severity guidance 보강**: top incident가 low/info이고 추가 근거가 context-only summary뿐이면 key finding severity도 low/info를 넘지 않도록 Stage2 guidance를 보강함

### [문서 및 진행상황 정리]
* **A~H 중간정리 작성/갱신**: `docs/99_A-H세트_중간정리.md`에 A~H 현재 성과, H R4 결과, 회귀 상태, LLM 샘플 검증 결과를 반영함
